# Prompt Studio

一个基于 MiniMax API 的对话式 Prompt 生成工具，帮助你通过简单对话生成高质量的提示词。

## 功能

- 对话式引导，逐步完善 Prompt
- 实时质量检查（6 项标准）
- 一键复制生成的 Prompt
- API Key 本地存储，安全不泄露

## 部署

本项目通过 GitHub Pages 部署，访问地址：
https://susu-xdpgq.github.io/Prompt-Engineering

## 使用

1. 打开网站，输入 MiniMax API Key
2. 描述你想要的提示词需求
3. 与 AI 对话补充细节
4. 复制生成的最终 Prompt
